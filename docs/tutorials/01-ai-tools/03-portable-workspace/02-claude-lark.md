# 从 0 到 1：用 Claude Code 操作飞书做个人效率系统

## 一篇完整的小白实操教程

很多人用 Claude Code，只把它当成写代码工具；很多人用飞书，也只是拿来聊天、写文档、看日历。

但如果把 **Claude Code + lark-cli + 飞书** 组合起来，就可以做出一个非常实用的个人效率系统。

你可以让 Claude Code 帮你：

- 查看今天日程；
    
- 整理个人待办；
    
- 把想法变成飞书文档；
    
- 整理读书笔记；
    
- 制定学习计划；
    
- 分析个人消费表格；
    
- 做每周复盘；
    
- 搭建内容创作资料库；
    
- 生成每日个人工作台。
    

简单说：

> **飞书负责保存你的资料，lark-cli 负责连接飞书，Claude Code 负责理解和执行。**

lark-cli 是飞书官方 CLI 工具，文档中提到它覆盖消息、文档、多维表格、电子表格、幻灯片、日历、邮箱、任务、会议、Markdown 等核心业务域，并提供 200+ 命令和多个 AI Agent Skills。

# 一、这门教程适合谁？

这篇教程适合：

|人群|适合原因|
|---|---|
|AI 工具小白|想知道 AI 除了聊天还能做什么|
|Claude Code 用户|想让 Claude Code 做更多自动化事情|
|飞书用户|想把飞书变成个人效率中心|
|学习者|想管理学习计划、笔记和复盘|
|内容创作者|想管理选题、素材和草稿|
|自由职业者|想管理任务、资料、计划和个人项目|

这篇教程不要求你懂复杂开发，也不要求你会写程序。

你只需要会三件事：

1. 安装 Claude Code；
    
2. 打开终端；
    
3. 复制提示词给 Claude Code。

# 二、最终你会搭建出什么？

学完以后，你会得到一个个人版的 **AI 效率系统**。

它包含 5 个核心模块：

|模块|用到的飞书能力|作用|
|---|---|---|
|今日日程|飞书日历|管理时间|
|个人待办|飞书任务|管理事情|
|个人文档|飞书文档|管理想法和笔记|
|个人表格|飞书电子表格 / 多维表格|管理数据和资料|
|个人复盘|飞书文档|管理成长|

最终效果是：

每天早上，你只需要对 Claude Code 说：

```text
请生成我的今日个人工作台。
```

它就可以帮你整理：

- 今天有哪些安排；
    
- 今天必须完成什么；
    
- 哪些任务还没做；
    
- 最近有哪些文档需要回顾；
    
- 今天应该优先做什么。

# 三、准备工作

在开始之前，你需要准备：

## 1. 一个飞书账号

建议先用自己的个人飞书空间测试，不要一开始就在重要空间里操作。

## 2. Claude Code

你需要本地已经可以使用 Claude Code。

如果你还没有安装 Claude Code，可以先完成 Claude Code 的基础安装。

## 3. Node.js 环境

因为 lark-cli 推荐通过 `npx` 安装，所以电脑里需要有 Node.js。

可以让 Claude Code 先检查：

```bash
node -v
npm -v
npx -v
```

如果这三个命令都能正常输出版本号，就说明环境基本没问题。

---

# 四、安装 lark-cli

## 第一步：让 Claude Code 检查环境

把下面这段话发给 Claude Code：

```text
请先检查当前电脑是否已经安装 Node.js、npm 和 npx。

依次执行：

node -v
npm -v
npx -v

然后告诉我结果是否正常。
不要做其他操作。
```

如果 Claude Code 返回了类似：

```bash
v22.x.x
10.x.x
10.x.x
```

说明可以继续。

---

## 第二步：安装 lark-cli

继续把这段发给 Claude Code：

```text
请帮我安装 lark-cli。

执行命令：

npx @larksuite/cli@latest install

安装完成后，再执行：

lark-cli --help

确认 lark-cli 是否安装成功。
```

如果安装成功，`lark-cli --help` 会输出命令帮助信息。

---

## 第三步：初始化飞书配置

继续发给 Claude Code：

```text
请初始化 lark-cli 的飞书应用配置。

执行命令：

lark-cli config init --new

注意：
如果命令输出浏览器授权链接，请把链接完整发给我。
不要跳过授权。
不要继续猜测。
等我在浏览器里完成授权后，再继续下一步。
```

这一步可能需要你打开浏览器，按照页面提示完成飞书授权。

---

## 第四步：登录飞书授权

配置完成后，让 Claude Code 执行：

```text
请继续执行飞书登录授权。

执行命令：

lark-cli auth login --recommend

如果输出授权链接，请把链接完整发给我。
等我完成浏览器授权后，再继续。
```

---

## 第五步：验证授权状态

授权完成后，让 Claude Code 执行：

```text
请检查 lark-cli 当前授权状态。

执行命令：

lark-cli auth status

然后告诉我当前是否已经登录成功，以及可以访问哪些权限。
```

如果状态正常，就可以开始实操课程。

# 五、最重要的安全规则

在正式使用之前，一定要记住：

> **只读操作可以直接执行，写入操作必须先 dry-run。**

## 什么是只读操作？

只读操作就是只查看，不修改。

比如：

- 查看日历；
    
- 查询任务；
    
- 读取文档；
    
- 搜索笔记；
    
- 分析表格。
    

这些操作风险比较低。

---

## 什么是写入操作？

写入操作会改变你的飞书内容。

比如：

- 创建任务；
    
- 创建文档；
    
- 修改表格；
    
- 发送消息；
    
- 删除内容；
    
- 更新日程。
    

这类操作必须先预览。

---

## 建议每次都加上的安全提示词

以后你让 Claude Code 操作飞书，都可以加上这段：

```text
安全要求：

1. 默认只读，不要直接写入。
2. 所有创建、修改、删除、发送消息等操作，都必须先 dry-run。
3. dry-run 后展示即将执行的命令、影响范围和写入内容。
4. 等我明确说“确认执行”后，才能真正执行。
5. 不要读取和本任务无关的私人聊天、邮箱、文档。
6. 不要把敏感信息输出到日志里。
```

# 第 1 课：认识 Claude Code + lark-cli

## 这一课解决什么问题？

很多人第一次看到这个组合会有点懵：

> Claude Code 不是写代码的吗？  
> 为什么它能操作飞书？  
> lark-cli 又是什么？

这一课先把逻辑讲清楚。

---

## 它们三个分别负责什么？

|工具|作用|
|---|---|
|Claude Code|理解你的需求，并在终端里执行命令|
|lark-cli|把终端命令转换成飞书操作|
|飞书|保存你的日程、任务、文档、表格和笔记|

可以用一句话理解：

> **Claude Code 是大脑，lark-cli 是手，飞书是资料库。**

---

## 本课实操目标

确认 Claude Code 能正常调用 lark-cli。

---

## 给 Claude Code 的提示词

```text
请验证 lark-cli 是否已经可用。

依次执行：

1. lark-cli --help
2. lark-cli auth status

要求：

1. 只做检查。
2. 不要创建、修改、删除任何飞书内容。
3. 如果缺少授权，请告诉我下一步应该执行什么命令。
```

---

## 本课完成标准

如果你看到：

- `lark-cli --help` 能正常输出；
    
- `lark-cli auth status` 显示已经登录；
    

就说明第 1 课完成。

# 第 2 课：查看今天日程，生成今日安排

## 场景

每天早上打开电脑，你想知道：

- 今天有什么安排；
    
- 哪些时间是空的；
    
- 今天适合先做什么；
    
- 有没有容易忘记的事情。
    

以前你要打开飞书日历自己看。  
现在可以让 Claude Code 帮你整理。

---

## 本课用到的飞书能力

飞书日历。

---

## 可以执行的命令

```bash
lark-cli calendar +agenda
```

---

## 给 Claude Code 的提示词

```text
请使用 lark-cli 查看我今天的飞书日历安排。

要求：

1. 只查询今天的日程。
2. 不要创建、修改、删除任何日程。
3. 按时间顺序整理。
4. 帮我找出空闲时间段。
5. 最后给我一个今日安排建议。

输出格式：

# 今日安排

## 一、今天的日程

## 二、空闲时间段

## 三、建议优先完成的事情
```

---

## 你会得到什么？

Claude Code 会把日历结果整理成类似这样：

```md
# 今日安排

## 一、今天的日程

- 09:00 - 10:00：英语学习
- 14:00 - 15:00：整理资料
- 20:00 - 21:00：跑步

## 二、空闲时间段

- 10:00 - 12:00
- 15:00 - 18:00

## 三、建议优先完成的事情

建议上午先完成需要专注的学习任务，下午处理整理类事项，晚上安排运动或复盘。
```

---

## 本课重点

这一课非常适合小白，因为它是 **只读操作**。

不会修改任何飞书内容，风险很低。

---

## 课后练习

让 Claude Code 帮你生成：

```text
请根据我今天的日程，帮我安排一个更合理的学习时间表。
```

# 第 3 课：创建个人待办清单

## 场景

你每天可能会有很多杂事：

- 背单词；
    
- 买东西；
    
- 跑步；
    
- 整理照片；
    
- 写读书笔记；
    
- 还信用卡；
    
- 给朋友回消息。
    

这些事情如果只放在脑子里，很容易忘。

这一课，我们让 Claude Code 把自然语言整理成飞书任务。

---

## 本课用到的飞书能力

飞书任务。

---

## 本课重点

这是第一次涉及写入操作，所以必须强调：

> **创建任务前，必须先 dry-run。**

---

## 给 Claude Code 的提示词

```text
请帮我把下面这些事情整理成飞书任务，但先不要真正创建，先 dry-run 给我看。

待办事项：

1. 今晚 8 点背 30 个英语单词
2. 明天上午买洗发水
3. 周六跑步 30 分钟
4. 周日前写完一篇读书笔记
5. 本周整理手机相册

要求：

1. 帮我整理任务标题。
2. 自动判断优先级。
3. 如果能设置时间，请给出建议时间。
4. 先 dry-run，不要直接创建。
5. dry-run 后告诉我即将创建哪些任务。
6. 等我确认后再真正创建。
```

---

## dry-run 后你应该检查什么？

你要看三件事：

|检查项|说明|
|---|---|
|任务标题是否正确|有没有理解错你的意思|
|时间是否正确|有没有把今天、明天、周六理解错|
|数量是否正确|有没有多建或少建任务|

确认没问题后，再对 Claude Code 说：

```text
确认执行，请创建这些飞书任务。
```

---

## 本课完成标准

你在飞书任务里能看到刚刚创建的待办事项。

---

## 课后练习

让 Claude Code 帮你整理一个周末待办清单：

```text
请帮我设计一个周末个人待办清单，包括学习、运动、整理房间、休息和娱乐。

先帮我整理任务，不要直接创建。
```

# 第 4 课：把碎片想法整理成飞书文档

## 场景

很多人脑子里有很多想法，但写不成正式文档。

比如：

```text
我想学英语，但是总是坚持不下来。我希望每天只学一点点，比如背单词、听一句英文、看一个短视频。最好能坚持 30 天，每周复盘一次。
```

这段话本身很零散，但 Claude Code 可以帮你整理成一篇结构清晰的飞书文档。

---

## 本课用到的飞书能力

飞书文档。

---

## 第一步：先生成 Markdown 内容

把下面提示词发给 Claude Code：

```text
请帮我把下面这段想法整理成一篇适合保存到飞书的 Markdown 文档。

原始想法：

我想学英语，但是总是坚持不下来。我希望每天只学一点点，比如背单词、听一句英文、看一个短视频。最好能坚持 30 天，每周复盘一次。

要求：

1. 文档标题叫《30 天英语学习计划》。
2. 内容要适合个人执行。
3. 帮我拆成每日任务和每周复盘。
4. 语言简单，不要写得太复杂。
5. 先只输出 Markdown。
6. 不要直接创建飞书文档。
```

---

## 第二步：确认内容后创建飞书文档

如果你觉得内容可以，再发：

```text
请把刚才这份 Markdown 创建成飞书文档。

要求：

1. 标题使用《30 天英语学习计划》。
2. 创建前先 dry-run。
3. dry-run 后展示文档标题和主要内容。
4. 等我确认后再执行。
```

---

## 你会得到什么？

最终你会得到一篇飞书文档：

```text
《30 天英语学习计划》
```

里面可能包含：

- 学习目标；
    
- 每日任务；
    
- 每周复盘；
    
- 打卡模板；
    
- 注意事项。
    

---

## 本课重点

不要一上来就让 Claude Code 直接创建文档。

推荐流程是：

```text
先生成内容 → 人工确认 → dry-run → 再创建
```

---

## 课后练习

让 Claude Code 帮你把下面这个想法整理成文档：

```text
我想开始运动，但不想办健身卡。我希望每天在家运动 15 分钟，主要练核心、拉伸和肩颈放松。
```

# 第 5 课：整理个人读书笔记

## 场景

你读完一本书，可能会随手记一些东西：

```text
这本书讲习惯养成。核心是不要靠意志力，要靠环境设计。
小习惯更容易坚持。每天进步一点点。
坏习惯不是靠克制，而是减少触发。
我觉得可以用到英语学习和运动上。
```

这段笔记有价值，但太乱了。

这一课让 Claude Code 帮你整理成标准读书笔记。

---

## 本课用到的飞书能力

飞书文档。

---

## 给 Claude Code 的提示词

```text
请把下面这段读书笔记整理成适合保存到飞书文档的内容。

要求：

1. 保留我的原始观点。
2. 帮我补充清晰的小标题。
3. 总结核心观点。
4. 提炼我可以马上行动的 3 个方法。
5. 加一个“我的个人启发”部分。
6. 输出 Markdown。
7. 先不要创建飞书文档。

原始笔记：

这本书讲习惯养成。核心是不要靠意志力，要靠环境设计。
小习惯更容易坚持。每天进步一点点。
坏习惯不是靠克制，而是减少触发。
我觉得可以用到英语学习和运动上。
```

---

## 建议输出结构

```md
# 读书笔记：习惯养成

## 一、这本书主要讲什么

## 二、核心观点

## 三、对我的启发

## 四、可以马上行动的 3 个方法

## 五、后续实践计划
```

---

## 创建飞书文档的提示词

内容确认后，再发：

```text
请把刚才整理好的读书笔记创建为飞书文档。

标题：《读书笔记：习惯养成》

要求：

1. 创建前先 dry-run。
2. dry-run 后展示文档标题和主要小标题。
3. 等我确认后再执行。
```

---

## 本课完成标准

你会得到一篇结构化读书笔记。

---

## 课后练习

找一本你最近看过的书，把你随手写的 5-10 条笔记发给 Claude Code，让它整理成飞书文档。

# 第 6 课：生成个人学习计划

## 场景

你想学一个新技能，比如：

- Claude Code；
    
- 英语；
    
- Python；
    
- AI 绘画；
    
- 视频剪辑；
    
- 写作；
    
- 摄影；
    
- 飞书自动化。
    

但最大的问题是：

> 不知道每天该学什么。

这一课让 Claude Code 帮你把目标拆成可执行计划。

---

## 本课用到的飞书能力

- 飞书文档；
    
- 飞书任务。
    

---

## 第一步：生成 14 天学习计划

给 Claude Code：

```text
请帮我生成一个 14 天 Claude Code 学习计划，并整理成飞书文档格式。

我的情况：

1. 我是新手。
2. 每天最多学习 1 小时。
3. 我希望以实战为主。
4. 最后能做出一个小作品。

要求：

1. 按天拆分学习任务。
2. 每天包含：学习目标、实操任务、完成标准。
3. 设计第 7 天和第 14 天复盘。
4. 语言要适合小白。
5. 输出 Markdown。
6. 先不要创建飞书文档。
```

---

## 第二步：创建学习计划文档

确认计划内容后，再发：

```text
请把这个 14 天学习计划创建成飞书文档。

要求：

1. 标题为《14 天 Claude Code 学习计划》。
2. 创建前先 dry-run。
3. 等我确认后再执行。
```

---

## 第三步：把每日计划创建成飞书任务

继续发：

```text
请把这个 14 天学习计划中的每日任务创建成飞书任务。

要求：

1. 创建前先 dry-run。
2. 每天一个任务。
3. 任务标题格式为：第 X 天：学习主题。
4. 每个任务描述里包含学习目标、实操任务和完成标准。
5. 等我确认后再真正创建。
```

---

## 本课完成标准

你会得到：

1. 一篇学习计划文档；
    
2. 14 个飞书任务。

# 第 7 课：分析个人消费表格

## 场景

你可以用飞书电子表格记录个人消费。

表格字段可以很简单：

|日期|类别|金额|备注|
|---|---|--:|---|
|5 月 1 日|餐饮|38|午饭|
|5 月 2 日|交通|12|地铁|
|5 月 3 日|学习|99|课程|
|5 月 4 日|娱乐|36|电影|

以前你只是记录，但很少分析。

现在可以让 Claude Code 读取表格，帮你生成消费分析报告。

---

## 本课用到的飞书能力

飞书电子表格。

---

## 第一步：准备消费表格

你可以先在飞书里建一个电子表格，字段如下：

```text
日期
类别
金额
备注
```

建议先填 10-20 条测试数据。

---

## 第二步：让 Claude Code 分析

```text
请使用 lark-cli 读取我的飞书电子表格，帮我分析本月消费情况。

表格字段包括：

- 日期
- 类别
- 金额
- 备注

请帮我分析：

1. 本月总消费。
2. 各类别消费金额。
3. 花钱最多的 3 个类别。
4. 是否有异常消费。
5. 下个月节省建议。

输出格式：

# 本月消费分析

## 一、总览

## 二、分类统计

## 三、主要消费来源

## 四、异常消费

## 五、下月建议

要求：

1. 只读取表格。
2. 不要修改表格。
3. 不确定的地方要说明。
4. 不要编造数据。
```

---

## 可能需要你提供什么？

Claude Code 可能会问你：

- 表格链接；
    
- spreadsheet token；
    
- sheet id；
    
- 表格名称。
    

如果它不知道怎么读取，就让它先执行：

```text
请先告诉我读取飞书电子表格需要哪些参数，不要直接操作。
```

---

## 本课完成标准

你得到一份个人消费分析报告。

---

## 本课重点

这一课让学员理解：

> AI 不只是写文章，它也可以分析表格数据。

---

## 课后练习

你可以把消费表格换成：

- 运动打卡表；
    
- 背单词记录表；
    
- 读书记录表；
    
- 睡眠记录表；
    
- 体重记录表。
    

然后让 Claude Code 分析趋势。

# 第 8 课：生成个人周复盘

## 场景

每周日晚上，你可能会想：

- 这周我到底做了什么？
    
- 哪些事情没完成？
    
- 为什么拖延？
    
- 下周怎么安排？
    
- 哪些事情值得继续坚持？
    

如果你平时用飞书记录日历、任务、文档，那么 Claude Code 就可以帮你自动生成周复盘。

---

## 本课用到的飞书能力

- 飞书日历；
    
- 飞书任务；
    
- 飞书文档。
    

---

## 给 Claude Code 的提示词

```text
请使用 lark-cli 帮我生成本周个人复盘。

时间范围：
本周一到今天。

请尽量参考：

1. 我的飞书日历。
2. 我的飞书任务。
3. 本周创建或更新过的飞书文档。

输出格式：

# 本周个人复盘

## 一、本周完成了什么

## 二、本周没有完成什么

## 三、做得比较好的地方

## 四、拖延或失败的原因

## 五、下周改进计划

## 六、下周最重要的 3 件事

要求：

1. 只读取信息。
2. 不要修改任何内容。
3. 如果某类数据查不到，就写“未查询到”。
4. 不要编造。
5. 对不确定的信息要标注“需要我确认”。
```

---

## 创建复盘文档

如果你觉得生成得不错，可以继续：

```text
请把这份复盘创建成飞书文档。

标题格式：

《个人周复盘-YYYY-MM-DD》

要求：

1. 创建前先 dry-run。
2. 展示即将创建的标题和主要内容。
3. 等我确认后再执行。
```

---

## 本课完成标准

你得到一篇飞书文档：

```text
《个人周复盘-日期》
```

---

## 本课重点

这一课是从“单点工具”进入“系统化使用”。

以前是：

```text
查日历
建任务
写文档
```

现在是：

```text
综合日历 + 任务 + 文档 → 生成个人复盘
```

---

## 课后练习

让 Claude Code 额外生成一版：

```text
请把这份周复盘改写成适合发朋友圈的简短版本。
```

# 第 9 课：搭建个人内容创作资料库

## 场景

如果你想写文章、做视频、发小红书、做公众号，经常会遇到一个问题：

> 灵感很多，但很容易丢。

你可以用飞书多维表格搭建一个个人内容创作资料库。

里面可以放：

- 选题；
    
- 标题；
    
- 核心观点；
    
- 素材来源；
    
- 发布状态；
    
- 发布时间；
    
- 备注。
    

---

## 本课用到的飞书能力

飞书多维表格。

---

## 第一步：让 Claude Code 设计字段

```text
请帮我设计一个个人内容创作资料库，适合放在飞书多维表格里。

我的内容方向：

1. AI 工具教学
2. 个人成长
3. 学习方法

请设计字段：

1. 选题标题
2. 内容类型
3. 目标用户
4. 核心观点
5. 素材来源
6. 状态
7. 发布时间
8. 是否已发布
9. 备注

要求：

1. 先给我字段设计。
2. 说明每个字段的用途。
3. 再给我 10 条示例选题。
4. 最后给我一个使用说明。
5. 先不要创建多维表格。
```

---

## 第二步：确认字段设计

你要重点检查：

|检查项|说明|
|---|---|
|字段是否太多|小白建议先控制在 8-10 个字段|
|状态是否清晰|比如：灵感、草稿中、已发布、已归档|
|是否适合自己|不要为了复杂而复杂|

---

## 第三步：创建多维表格

确认后，再发：

```text
请使用 lark-cli 创建这个个人内容创作资料库。

要求：

1. 创建前先 dry-run。
2. 字段按照刚才设计。
3. 示例数据先不要写入。
4. dry-run 后展示表格名称、字段列表和字段类型。
5. 等我确认后再创建。
```

---

## 第四步：写入示例选题

表格创建成功后，可以继续：

```text
请把刚才生成的 10 条示例选题写入这个多维表格。

要求：

1. 写入前先 dry-run。
2. 展示即将写入的 10 条记录。
3. 等我确认后再执行。
```

---

## 本课完成标准

你会得到一个个人内容创作资料库。

---

## 本课重点

这一课很重要，因为它不是简单写文档，而是在设计一个个人系统。

你可以这样理解：

```text
飞书文档适合放长内容
飞书多维表格适合放结构化资料
Claude Code 负责帮你设计和维护
```

---

## 课后练习

把内容方向换成：

```text
英语学习笔记、旅行攻略、读书笔记
```

让 Claude Code 重新设计一个资料库。

# 第 10 课：打造每日个人工作台

## 场景

前面 9 课已经学会了：

- 查日历；
    
- 建任务；
    
- 写文档；
    
- 整理读书笔记；
    
- 生成学习计划；
    
- 分析表格；
    
- 做周复盘；
    
- 搭建内容库。
    

最后一课，把它们组合起来，做成一个每日个人工作台。

每天早上，只要打开 Claude Code，说一句：

```text
请生成我的今日个人工作台。
```

它就会帮你汇总今天最重要的信息。

---

## 本课用到的飞书能力

- 飞书日历；
    
- 飞书任务；
    
- 飞书文档；
    
- 飞书表格；
    
- 飞书多维表格。
    

---

## 给 Claude Code 的完整提示词

```text
请使用 lark-cli 帮我生成今日个人工作台。

请汇总：

1. 今天的飞书日历。
2. 今天的飞书任务。
3. 最近 3 天创建或修改过的飞书文档。
4. 本周未完成的任务。
5. 最近的学习计划文档。
6. 最近的个人复盘文档。
7. 如果能读取内容创作资料库，请列出当前可以推进的 3 个选题。

输出格式：

# 今日个人工作台

## 一、今天的时间安排

## 二、今天必须完成的事情

## 三、今天适合推进的学习任务

## 四、最近需要回顾的文档

## 五、内容创作建议

## 六、可能被我忽略的事情

## 七、今日建议安排

要求：

1. 只读取，不要写入。
2. 不要读取无关私人内容。
3. 查不到的信息要说明“未查询到”。
4. 不要编造。
5. 如果需要我提供表格链接或文档链接，请明确告诉我。
```

---

## 创建每日工作台文档

如果你希望每天保存一份记录，可以继续：

```text
请把今日个人工作台创建成飞书文档。

标题格式：

《今日个人工作台-YYYY-MM-DD》

要求：

1. 创建前先 dry-run。
2. 展示即将创建的标题和主要内容。
3. 等我确认后再执行。
```

---

## 本课完成标准

你最终得到一份：

```text
《今日个人工作台-日期》
```

它会成为你每天的行动入口。

## 本课重点

这一课是整个课程的最终项目。

# 八、常见问题

## 1. Claude Code 可以直接替我点浏览器授权吗？

不建议这样做。

授权链接需要你自己打开浏览器确认。  
Claude Code 可以帮你运行命令、提取链接，但最终授权最好由你自己完成。

---

## 2. 会不会误删飞书内容？

只要你遵守这条规则，风险就会低很多：

```text
所有写入、修改、删除操作必须先 dry-run。
```

不要让 Claude Code 直接执行删除、批量修改、群发消息等操作。

---

## 3. 我不会命令行，可以学吗？

可以。

这门课的核心不是让你背命令，而是学会把需求说清楚。

你可以大部分时间都用提示词驱动 Claude Code。

---

## 4. 飞书里没有数据怎么办？

可以先手动准备一些测试数据：

- 建 3 个日程；
    
- 建 5 个任务；
    
- 写 2 篇文档；
    
- 建 1 个消费表格；
    
- 建 1 个内容资料库。
    

有了数据以后，Claude Code 才能帮你分析和整理。

---

## 5. 这个适合个人使用吗？

非常适合。

尤其适合这些个人场景：

- 学习计划；
    
- 读书笔记；
    
- 写作素材；
    
- 旅行攻略；
    
- 消费记录；
    
- 每周复盘；
    
- 自媒体选题；
    
- 个人任务管理。

# 九、最终总结

这套方法的关键，不是让你学会多少命令，而是让你理解一个新思路：

飞书不再只是聊天和文档工具，而是你的个人资料库。

Claude Code 也不再只是写代码工具，而是你的个人效率助理。

```text
个人 AI 效率系统
```

它可以帮你管理：

- 时间；
    
- 任务；
    
- 笔记；
    
- 学习；
    
- 表格；
