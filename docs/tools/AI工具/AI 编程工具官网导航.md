## 七、简单使用建议

如果是新电脑，建议先安装基础环境：

1. Node.js
    
2. Git
    
3. Trae
    
4. Claude Code
    
5. CC Switch 可视化版
    
6. Obsidian
    

如果只是学习 AI 编程，可以优先关注：

- Trae：中国版 AI IDE
    
- Claude Code：终端 AI 编程助手
    
- CC Switch：Claude Code 等工具的可视化管理器
    
- DeepSeek / MiniMax：国产模型 API 平台
    
- Obsidian：整理学习笔记和提示词文档
    

这套组合比较适合做 AI 编程学习、AI 工具折腾、个人知识库沉淀，以及后续整理成教程文章。
