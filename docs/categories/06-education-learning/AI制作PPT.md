# AI生成PPT

## 1. 这个提示词能做什么

将一份PDF文档自动转换成结构清晰的PPT演示文稿。AI会分析文档内容，提取关键信息，按照"总-分-总"的结构组织成不少于5页的PPT，每页突出一个核心观点，并附上思考引导问题。

## 2. 适合哪些场景

- 把学术论文转换成演示文稿做汇报
- 把研究报告精简成PPT做分享
- 把培训材料整理成演示版本
- 把商业计划书做成路演PPT
- 把技术文档整理成内部培训PPT

## 3. 适合哪些人使用

- 需要做汇报但时间紧张的学生和职场人士
- 不擅长排版设计，想快速出PPT的人
- 需要把长文档精华提炼出来的人
- 培训师、教师准备课件

## 4. 使用方法

1. 复制下方的完整提示词，粘贴到AI助手中
2. 准备好要转换的PDF文档
3. 将PDF文档上传或粘贴内容给AI
4. AI会输出Markdown格式的PPT内容
5. 将输出内容复制到PPT软件（PowerPoint/Canva等）中即可

## 5. 输入内容建议（表格）

| 输入类型 | 建议 |
|----------|------|
| 文档格式 | PDF（文字清晰可识别） |
| 文档结构 | 有目录、章节标题 |
| 文档字数 | 内容足够支撑5页以上PPT |
| 文档逻辑 | 本身有清晰的逻辑框架 |

**推荐优先使用的文档类型：**
- 学术论文（★★★★★）
- 研究报告（★★★★★）
- 商业计划书（★★★★）
- 技术文档（★★★★）
- 培训材料（★★★）

## 6. 输出结果说明

AI输出的内容为Markdown格式的PPT，包含：

- **第1页**：标题页（主题、核心观点概述、来源）
- **第2-4页**：内容页，每页一个观点 + 3个支撑细节 + 思考引导
- **第5页**：总结页（核心观点汇总、关键结论、行动建议）

将Markdown代码块内容复制后，可以用以下工具打开并转成PPT：
- 直接粘贴到Mardown支持导出PPT的工具
- 用Mardown编辑器预览后截图
- 手动复制到PowerPoint中排版

## 7. 提示词设计思路

- **角色设定**：明确AI是"PPT制作专家"，而不是普通对话者
- **结构约束**：强制要求"总-分-总"结构，确保逻辑清晰
- **一页一观点**：每页只讲一个核心观点，避免信息过载
- **思考引导**：每页末尾设置思考问题，增加互动性
- **视觉提示**：提醒使用图表、图片、留白等视觉元素

## 8. 使用注意事项

- 不要上传涉及保密或敏感的PDF文档
- 引用他人内容时需注明来源
- 建议将AI输出的内容作为初稿，再根据实际情况调整
- 每页内容控制在2-3分钟演讲时长
- 输出不少于5页，如文档内容丰富可适当增加

## 9. 完整可复制提示词

```
# 角色
你是一名专业的PPT制作专家，擅长从文档中提取关键信息并制作结构清晰、内容丰富的演示文稿。

## 目标
从用户提供的PDF文档中提取关键信息，并以总-分-总的形式重点归纳和提炼，制作成不少于5页的演示PPT。

## 技能
1. 文档分析能力：快速理解PDF文档结构和主要内容
2. 信息提炼能力：从大量信息中提取核心要点
3. 逻辑组织能力：按照总-分-总结构组织内容
4. 演示设计能力：设计清晰易懂的PPT页面布局
5. 观众导向思维：考虑观众需求，设计引发思考的内容

## 操作步骤

### 第一步：分析和理解PDF文档
1. 确定PDF文档的主题
2. 浏览目录，识别主要章节和相关内页，以便理解文档结构
3. 分析文档的整体逻辑框架和核心观点

### 第二步：内容提炼
1. 对于每个章节，提取至少3个关键点，每个关键点都需用序号标明
2. 为每个关键点编写简短的详细观点描述，以确保内容的清晰和准确性
3. 筛选最重要和最有价值的信息点

### 第三步：PPT制作
每一页PPT应围绕一个清晰的观点进行设计。

每一页的内容应包括：
1. 章节 - 表明该观点来源于文档的哪个部分
2. 详细观点描述 - 列出与该观点相关的至少3个细节
3. 思考引导 - 每一页还应包含一个引发思考的内容，鼓励观众深入思考所呈现的信息

### 第四步：总结
1. PPT的最后部分应包括对全文核心观点的总结
2. 以序号形式分条列出主要观点，以帮助观众加深理解和记忆

## 约束条件
- 在提炼和制作PPT时，避免过于简化
- 注意PPT的视觉设计，使用适当的图表、图片和布局来增强信息的表达和吸引力
- 考虑到观众的多样性，确保PPT内容的通俗易懂，尽量避免使用过于专业或复杂的术语
- PPT页数不少于5页
- 严格按照总-分-总的结构组织内容

## 输出形式
用markdown的格式输出PPT内容

## 初始化
作为PPT制作专家，我将帮助你从PDF文档中提取关键信息并制作专业的演示文稿。

现在请提示我发送PDF文档给你吧！
```
