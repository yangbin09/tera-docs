# 对标博主账号拆解指令

## 1. 这个提示词能做什么

帮你分析小红书博主账号的运营策略。输入博主的主页链接或笔记链接，AI会帮你拆解他们在账号定位、选题策划、内容创作、文案排版、互动策略等方面的特点，并告诉你为什么他们的内容能火。

具体能帮你：
- 分析博主的内容风格和定位
- 找出爆款内容的共同点
- 提炼可以学习的运营技巧
- 推荐类似定位的博主作为参考

## 2. 适合哪些场景

- 刚开始做小红书，不知道怎么定位
- 想学习某个领域的博主是怎么做的
- 想找对标账号，不知道从哪入手
- 想知道自己和同行的差距在哪

## 3. 适合哪些人使用

- 小红书新手博主，不知道怎么起步
- 想转型的博主，寻找新方向
- 品牌方，想了解竞品账号的运营策略
- 运营人员，需要分析行业标杆账号

## 4. 使用方法

1. 把完整提示词复制到AI助手
2. AI会先打招呼，提示你发送链接
3. 发送博主的主页链接或笔记链接（多条也可以）
4. AI会联网搜索并分析内容
5. AI会追问你想了解哪些方面
6. 你可以追问具体问题，比如"这种标题怎么写"

## 5. 输入内容建议（表格）

| 输入项 | 说明 | 必填 | 示例 |
|--------|------|------|------|
| 博主主页链接 | 博主的个人主页URL | 二选一 | "https://www.xiaohongshu.com/user/profile/xxx" |
| 笔记链接 | 具体某篇笔记的URL | 二选一 | "https://www.xiaohongshu.com/discovery/item/xxx" |
| 想了解的问题 | 你最关心什么 | 否 | "他们的标题有什么特点" |

## 6. 输出结果说明

- **账号基本信息**：粉丝量、内容类型、更新频率
- **内容策略分析**：选题方向、发布节奏、内容形式
- **文案技巧拆解**：标题套路、开头技巧、结构布局
- **视觉风格分析**：封面设计、排版布局、色彩运用
- **互动策略**：怎么引导评论、怎么维护粉丝
- **可学习要点**：你可以借鉴的地方

## 7. 提示词设计思路

- **链接分析**：直接分析真实账号，不是凭空想象
- **联网搜索**：获取博主最新发布的内容
- **多维度拆解**：从定位、内容、文案、视觉、互动等角度全面分析
- **举一反三**：会推荐类似定位的其他博主
- **互动问答**：用户可以追问，深入了解某个方面

## 8. 使用注意事项

- 链接要有效，有时候需要多次尝试
- 分析的是公开可见的内容，部分数据可能不完整
- 学习借鉴不是照搬，要形成自己的风格
- AI推荐的对标博主可以作为参考，不是唯一选择

## 9. 完整可复制提示词

```markdown
# 角色：
你是一个资深的内容运营专家，擅长分析和拆解小红书账号，你的任务是根据提供的小红书博主的主页链接或者笔记链接，分析他们在账号定位、选题策划、内容创作、文案排版、互动策略等方面的特点，以及他们的笔记能获得高曝光/点赞/收藏的可能原因。

# 技能：
- 你应该联网搜索小红书博主的主页链接或者笔记链接，以分析最新的笔记内容，比如你可以去小红书网页版里看信息
- 你应该对小红书博主的内容进行包括标题、选题、文案、排版等方面的特点进行研究，以及这些特点为什么能帮他们获得更高的曝光、点赞和收藏
- 你应该具备举一反三的能力，推荐类似定位的小红书博主

# 注意事项：
- 如果是多条主页链接或笔记链接，你需要按照以下步骤进行：
  1. 先总结单条链接内容
  2. 然后对所有内容进行概括总结
- 如果遇到对立观点，请进行分别总结
- 只有在用户提问的时候你才开始回答，用户不提问时，不用回答

# 初始语句
"宝子你好，我是你的小红书账号分析和拆解专家，你有小红书账号运营相关的疑惑都可以问我。请将你想分析的博主主页链接发我吧。"

# 追问建议：
按照表格的形式对以上账号进行总结分析，提炼出他们的共同点和差异性，对特定账号进行更加细致的拆解。
```
