# 爆款短视频脚本指令

## 1. 这个提示词能做什么

帮助创作适合各平台的爆款短视频脚本。AI会收集你的内容需求，按选定结构生成完整脚本，包括标题、正文、分镜头脚本和拍摄建议。

## 2. 适合哪些场景

- 创作短视频内容脚本
- 需要系统化的脚本创作流程
- 想学习短视频写作结构
- 需要分镜头脚本进行拍摄

## 3. 适合哪些人使用

- 短视频创作者
- 自媒体博主
- 视频拍摄团队
- 想要系统学习脚本写作的人

## 4. 使用方法

1. 把提示词复制到AI对话框
2. 回答AI的信息收集问题
3. 选择一个写作结构
4. 获得完整脚本
5. AI做最后润色
6. 获得分镜头脚本表格

## 5. 输入内容建议

| 信息 | 说明 | 示例 |
|------|------|------|
| 字数要求 | 不超过1000字 | 800字 |
| 目标人群 | 性别、年龄 | 25-35岁职场女性 |
| 内容主题 | 要讲什么 | 职场穿搭技巧 |
| 内容风格 | 严肃/幽默/温馨等 | 简洁实用 |
| 发布平台 | 抖音/小红书等 | 抖音 |
| 写作结构 | 5种选1种 | PREP结构 |
| 其他信息 | 产品/情节等 | 推荐3款单品 |

## 6. 输出结果说明

- **标题**：有爆款潜质的标题
- **正文脚本**：完整口播/字幕内容
- **撰写思路说明**：为什么这样写
- **分镜头脚本表格**：场景、镜号、画面、景别、机位、动作、台词、时长

## 7. 提示词设计思路

5种核心写作结构：
1. **PREP结构**：观点→理由→案例→观点
2. **对比结构**：错误→负面→正确→正面
3. **FIRE结构**：事实→解读→反应→结果
4. **RIDE结构**：风险→利益→差异→影响
5. **强化IP结构**：痛点→获得感→信任感→解决方案

核心约束：自然表达、不夸张、有撰写思路说明。

## 8. 使用注意事项

- **自然语言**：不要机器感，不要太夸张
- **逻辑清晰**：段落间过渡自然
- **符合调性**：不同平台风格不同
- **有拍摄性**：方便转化成视频
- **选择对的结构**：根据内容类型选

## 文案结构

### 1. PREP结构
**P（Point）观点 + R（Reason）理由 + E（Example）案例 + P（Point）观点**

- **P（观点）**：你要在第一时间亮出你的观点
- **R（理由）**：给出你为什么这么说的理由
- **E（案例）**：说出案例证明你的观点
- **P（观点）**：回归到观点，重复你的结论

### 2. 对比结构
**错误操作 + 负面结果展示 + 正确方法 + 正向结果展示**

### 3. FIRE结构
**Fact事实 + Interpret解读 + Reaction反应 + Ends结果**

### 4. RIDE结构
**Risk风险 + Interest利益 + Difference差异 + Effect影响**

### 5. 强化IP结构
**痛点 + 用户获得感 + IP信任感 + 解决方案**

## 信息收集问题

在开始创作前，需要收集以下信息：

1. **字数要求**：不超过1000个汉字
2. **目标人群**：性别、年龄等
3. **内容主题**：例如：宠物狗鸡胸肉狗粮制作
4. **内容风格**：严肃认真、诙谐幽默、夸张、温馨、抒情、简洁、感性、励志、怀旧、故事化
5. **发布平台**：小红书、抖音、视频号、公众号、B站、快手、头条号等
6. **写作结构**：PREP结构、对比结构、FIRE结构、RIDE结构、强化IP结构
7. **其他信息**：特定情节、产品信息等

## 工作流程

### 第一步：信息收集
将信息收集问题完整内容发送给用户，要求用户认真按照问题提供信息。

### 第二步：文案创作
根据用户提供的关键信息，明确角色，回顾技能，严格按照文案结构格式撰写爆款文案。

**具体要求**：
- 文案结构中每段内容之间过渡自然，要有逻辑
- 不要重复啰嗦表达同一个意思，也不要跳跃性太强
- 文案语言风格一定要自然，符合平台调性要求
- 不要有惊叹和太夸张的语气，不要有反问句
- 不要有机器语言的生硬感觉
- 附上撰写思路说明

### 第三步：文案润色
扮演一名资深的中文老师，对生成的文案做整体修改润色，使其语言更自然，可读性更强，并重新输出最终方案。

### 第四步：分镜头脚本
输出一份短视频分镜头脚本，包含：
- 拍摄场景
- 镜号
- 画面描述
- 景别
- 拍摄机位
- 人物动作
- 台词
- 时长

**注意**：必须用表格形式展示

- 内容深度要求高
- 弹幕文化
- 中长视频为主
