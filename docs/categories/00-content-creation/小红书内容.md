# 小红书爆款文案指令

## 1. 这个提示词能做什么

帮助创作小红书风格的爆款文案，包括有吸引力的标题、口语化且有感染力的正文、以及合适的SEO标签。专门针对小红书平台特点设计。

## 2. 适合哪些场景

- 创作小红书种草笔记
- 制作产品推荐类内容
- 写生活方式分享文章
- 制作知识干货类小红书内容

## 3. 适合哪些人使用

- 小红书博主
- 想要在小红书推广产品的商家
- 自媒体内容创作者
- 想要学习小红书文案的营销人员

## 4. 使用方法

1. 把提示词复制到AI对话框
2. 告诉AI你想创作的主题
3. 获得5个爆款标题供选择
4. 获得一篇完整正文
5. 获得SEO标签建议
6. 获得首图建议

## 5. 输入内容建议

| 内容 | 说明 |
|------|------|
| 创作主题 | 要写什么内容 |
| 产品信息 | 如果是产品推荐，提供产品特点 |
| 目标受众 | 你的读者是谁 |
| 创作目的 | 种草/分享/教程等 |

## 6. 输出结果说明

- **5个标题**：每个不超过20字，带emoji，有吸引力
- **正文内容**：口语化、每段有emoji、有互动引导
- **SEO标签**：以#开头，5-10个相关标签
- **首图建议**：配图方向和风格建议

## 7. 提示词设计思路

小红书文案的核心要素：
1. 标题要抓眼球：用数字、情绪词、悬念
2. 正文要口语化：像朋友聊天一样
3. 适当使用emoji：增加活力和视觉吸引力
4. 引导互动：让读者愿意评论和收藏

核心约束：严格控制字数，符合平台调性。

## 8. 使用注意事项

- **标题控制**：20字以内，不要太长
- **口语化**：不要书面语，要接地气
- **真实感**：分享真实体验，不要过度营销
- **标签相关**：标签要跟内容高度相关
- **避免违禁词**：遵守小红书社区规范

## 标题创作技巧

### 1. 二极管标题法
**基本原理**：
- 本能喜欢：最省力法则和及时享受
- 动物基本驱动力：追求快乐和逃避痛苦，由此衍生出2个刺激：正刺激、负刺激

**标题公式**：
- 正面刺激：产品或方法+只需1秒(短期)+便可开挂(逆天效果)
- 负面刺激：你不XXX+绝对会后悔(天大损失)+(紧迫感)

## 正文写作技巧

### 1. 写作风格
- **热情洋溢**: 保持积极向上的语调
- **亲切自然**: 像朋友聊天一样自然
- **真实可信**: 分享真实体验和感受

### 2. 内容结构
- **痛点引入**: 开头描述用户痛点，引起共鸣
- **步骤说明**: 提供具体可操作的步骤
- **效果展示**: 展示使用后的效果和变化

### 3. 互动技巧
- **求助式互动**: "姐妹们，有没有遇到过这种情况？"
- **分享式互动**: "必须分享给你们这个宝藏发现！"
- **提问式互动**: 在文末提出问题引导评论

### 4. 语言特色
- **口头禅使用**: "真的真的"、"绝绝子"、"爱了爱了"
- **爆炸词运用**: 使用带有强烈情感的词汇
- **口语化表达**: 贴近日常对话的表达方式

## 工作流程

### 1. 主题输入阶段
- 用户输入想要创作的内容主题
- 可以包括产品信息、目标受众、创作目的等

### 2. 标题创作阶段
- 根据主题创作5个不同风格的标题
- 每个标题都包含适当的emoji
- 严格控制字数在20字以内

### 3. 正文创作阶段
- 根据主题创作符合小红书风格的正文
- 每个段落包含适当的emoji
- 采用口语化、亲切的表达方式

### 4. SEO标签生成
- 根据主题生成相关的SEO标签
- 包括核心关键词、关联关键词、高转化词等
- 标签格式以#开头

### 5. 配图建议
- 根据内容主题给出首图建议
- 提供具体的拍摄或设计建议
